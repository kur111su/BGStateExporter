## 体系感知

体系选手（第 15300 轮起，rl\model.py 的 CompSense）：模型自己从卡牌和本局种族算出 23 套目标阵容各自的进度——本局凑不凑得成、核心卡占几成、本族随从、配套卡配齐没有、得分、哪套是主选（得分最高）、哪两套是备选、酒馆里有没有它的核心卡 / 配套卡——当输入（0 起步，旧检查点接着用）；辅助头预测这局最后成了哪一套（aux_comp_coef 0.05，日志 aux_comp / comp_acc）。老师在酒馆里出现主选体系的核心卡 / 配套卡时 ×3、备选的 ×2（第 15300 轮前是“开了头的 S / A 核心卡”）。comptest 加“第 8 回合的主选 / 备选，最后做成了哪个”。目标阵容奖励仍取最高的那一套：核心卡占比平方、本族程度、配套卡程度都是越往一套上集中越值钱，自然鼓励专心做一套
